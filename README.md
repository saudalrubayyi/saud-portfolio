# Saud Alrubayyi — Professional Portfolio Website

A bilingual (Arabic/English), responsive, static portfolio. No build tools or paid services required.

## Files
- `index.html` — all site sections
- `styles.css` — responsive styling
- `script.js` — translations, language switching, project filtering, mobile navigation
- `assets/portfolio.pdf` — downloadable PDF portfolio

## Preview locally
Open `index.html` in your browser, or run `python3 -m http.server 8000` in this folder and navigate to `http://localhost:8000`.

## Publishing
- **GitHub Pages:** Upload the folder contents to a repository and enable Pages in the repository settings, choosing the main branch and root directory.
- **Netlify:** Drag-and-drop the folder into Netlify's manual deploy UI.
- **Vercel:** Import a repository containing these files; deploy as a static site (no build command).

## Personalization
- Edit biographical and project text in `script.js` (Arabic and English).
- Update the contact links in `index.html`.
- Replace `assets/portfolio.pdf` with the latest PDF; it is currently the English PDF portfolio prepared in the prior step.
- The visual graphics are original SVG illustrations, not photographs or screenshots of events.
- Add a verified LinkedIn URL and your own approved event/project photos when available.

This package is **ready for deployment**, but not yet published to a public domain.
